## 文件组织概述

E3D 数据库采用**页式存储结构**（Page-based Storage），类似于现代数据库管理系统的存储方式。

### 核心特性

- ✅ 固定页面大小（默认 4KB，可配置）
- ✅ 页面编号从 1 开始
- ✅ 多种页面类型支持不同功能
- ✅ 页面级缓存机制
- ✅ 扩展号支持多数据库

### 页面组织结构

```
┌─────────────────────────────────────────────────┐
│ 数据库文件                                       │
├─────────────────────────────────────────────────┤
│ 页面 0: 数据库描述符                             │
│   - 页面大小、页面数量等基本信息                  │
├─────────────────────────────────────────────────┤
│ 页面 1: 文件信息页面                             │
│   - 签名验证、版本信息                            │
├─────────────────────────────────────────────────┤
│ 页面 2: 引用数组页面                             │
│   - 属性引用数组                                  │
├─────────────────────────────────────────────────┤
│ 页面 3-N: 数据页面                               │
│   - 用户数据存储                                  │
│   - 类型 5: 数据页面                             │
│   - 类型 7: 特殊页面                             │
│   - 类型 8: 索引页面                             │
├─────────────────────────────────────────────────┤
│ 会话页面 (由页面0指向)                           │
│   - 会话信息管理                                  │
└─────────────────────────────────────────────────┘
```

## 页面结构

### 通用页面头

每个页面都包含一个通用的页面头结构：

```c
struct PageHeader {
    int page_type;        // 页面类型 (1-8)
    int type_id;          // 类型标识
    int db_handle;        // 数据库标记
    int ext_no;           // 扩展号
    int page_size;        // 页面大小
    // ... 其他字段
};
```

### 页面大小

- **默认页面大小**: 4 KB (4096 字节)
- **可配置**: 通过属性 ID 107487840 获取
- **页面大小存储在**: 页面1 的偏移 +8 (v24[2])

### 页面数量

- **总页面数**: 存储在页面1 的偏移 +12 (v24[3])
- **可配置**: 通过属性 ID 223355190 获取

## 页面类型

E3D 数据库支持多种页面类型，每种类型都有特定的用途：

### 类型 1: 引用数组页面

**页面号**: 2  
**大小**: 512 字节

**用途**: 存储属性引用数组

```c
struct RefArrayPage {
    int page_type;        // 必须为 1
    int array_count;      // 数组长度
    int refs[...];        // 引用数组
};
```

### 类型 3: 会话页面

**用途**: 存储会话信息

```c
struct SessionPage {
    int page_type;        // 必须为 3
    int session_id;       // 会话标识
    int db_handle;        // 数据库标记
    int session_mark;     // 会话标记
    // ... 其他会话信息
};
```

### 类型 5: 数据页面

**用途**: 存储用户数据

**子类型标识**:

| 类型标识 | 十六进制值 | 用途描述 |
|---------|-----------|---------|
| 7618377 | 0x743F11 | 主要数据页面 |
| 13387743 | 0xCC5D1F | 辅助数据页面 |
| 86284645 | 0x5256C75 | 索引数据页面 |
| 63068511 | 0x3C0A13F | 属性数据页面 |
| 66156832 | 0x3F22C60 | 扩展数据页面 |

```c
struct DataPage {
    int page_type;        // 必须为 5
    int type_id;          // 类型标识
    int db_handle;        // 数据库标记
    int ext_no;           // 扩展号
    int page_no;          // 页面号
    int bucket_id;        // 桶ID (低13位: 0x1FFF)
    char data[...];       // 用户数据
};
```

**桶索引**:
- 桶ID 存储在类型标识的第13-25位 (低13位: 0x1FFF)
- 用于快速查找和数据索引

### 类型 7: 特殊页面

**用途**: 特殊功能页面（如元数据页面、日志页面等）

### 类型 8: 索引页面

**用途**: 数据索引页面

## 索引和桶结构

### 桶系统 (Bucket System)

E3D 数据库使用桶系统来组织和管理数据页面。

#### 桶索引

**桶ID范围**: 0x0000 - 0x1FFF (0 - 8191)

**桶ID编码**:
```c
// 从类型标识中提取桶ID
bucket_id = (type_id >> 13) & 0x1FFF;
```

#### 桶统计

**存储位置**: 缓存条目偏移 +48 和 +384

```c
struct BucketStats {
    int max_bucket_id;     // 最大桶ID (偏移 +48)
    int bucket_count;      // 桶统计计数 (偏移 +384)
};
```

## 数据访问流程

### 读取页面流程

```
应用程序请求页面
    ↓
DB3_ 层: db_read_page
    ↓
包装层 (参数ID 288)
    ↓
DB2_ 层: DB2_ReadPage (2.4.0)
    ↓
1. 检查页面号有效性
2. 读取页面 1 获取文件信息
3. 验证签名和标记
4. 读取请求的页面
    ↓
DB1_ 层: DB1_GetPage
    ↓
1. 检查 PLU 缓存
2. 如果缓存命中:
   a. 增加页面锁计数
   b. 返回缓存页面
3. 如果缓存未命中:
   a. 分配新的页面帧
   b. 从文件读取页面
   c. 添加到 PLU 缓存
   d. 返回页面数据
    ↓
底层 I/O: DB_ReadPage
    ↓
文件系统读取
    ↓
返回页面数据给应用程序
```

### 写入页面流程

```
应用程序写入页面
    ↓
DB3_ 层: db_write_page
    ↓
包装层 (参数ID 290)
    ↓
DB2_ 层: DB2_WritePage (2.4.2)
    ↓
1. 检查页面类型 (必须 ≤ 8)
2. 读取页面 1 获取文件信息
3. 验证会话页面 (如果是会话页面)
4. 检查页面类型一致性
5. 更新页面 0 的页面计数
    ↓
DB1_ 层: DB1_WritePage
    ↓
1. 检查 PLU 缓存
2. 如果缓存命中:
   a. 更新缓存页面
   b. 设置脏标记
   c. 异步写入磁盘
3. 如果缓存未命中:
   a. 分配新的页面帧
   b. 添加到 PLU 缓存
   c. 立即写入磁盘
    ↓
底层 I/O: DB_WritePage
    ↓
文件系统写入
    ↓
返回成功状态给应用程序
```

## PLU 缓存系统

### 缓存条目结构

每个 PLU 缓存条目占用 28 字节：

```c
struct PLUEntry {
    // 偏移 +0
    void *page_frame;      // 页面帧指针 (4 字节)
    
    // 偏移 +4
    int prev_entry;        // 前一个条目索引 (4 字节)
    int next_entry;        // 后一个条目索引 (4 字节)
    
    // 偏移 +12
    int page_no;           // 页面号 (4 字节)
    
    // 偏移 +16
    int ext_no;           // 扩展号 (4 字节)
    
    // 偏移 +20
    int db_handle;         // 数据库标记 (4 字节)
    
    // 偏移 +24
    struct {
        unsigned short lock_count;    // 锁计数 (14 位)
        unsigned short flags;         // 标志位
        unsigned char is_dirty;       // 脏标记 (1 位)
        unsigned char is_pinned;      // 固定标记 (1 位)
        unsigned char is_cached;      // 缓存标记 (1 位)
    };
    
    // 偏移 +26
    struct {
        unsigned char is_accessed;   // 访问标记 (1 位)
        unsigned char reserved;      // 保留 (7 位)
    };
};
```

### 缓存管理

**查找算法**: 哈希表 + 双向链表

**替换策略**: LRU (Least Recently Used)

**锁机制**: 读锁和写锁

**写回策略**: 异步写回
