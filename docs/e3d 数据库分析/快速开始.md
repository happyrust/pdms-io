# E3D 数据库读取工具 - 快速开始指南

## 前提条件

- Python 3.6 或更高版本
- E3D/PDMS 数据库文件

## 安装

无需安装，直接使用 `e3d_db_reader_fix.py` 工具即可。

## Python API 使用

### 基本用法

```python
from e3d_db_reader_fix import E3DDatabase

# 打开数据库
db = E3DDatabase('/path/to/database')

# 查看数据库信息
print(f"数据库ID: {db.metadata['db_id']}")
print(f"页面大小: {db.metadata['page_size']}")
print(f"总页数: {db.metadata['page_count']}")

# 读取指定页面
page_data = db.read_page(0)

# 解析页面头
page_info = db.parse_page_header(page_data)
print(f"页面类型: {page_info['page_type']}")
print(f"页面类型名称: {page_info['page_type_name']}")

# 扫描所有页面
scan_results = db.scan_pages()
for page_type, page_nums in scan_results.items():
    print(f"类型 {page_type}: {len(page_nums)} 个页面")

# 查找包含 ASCII 文本的页面
ascii_pages = db.find_ascii_pages(min_chars=64)
for page_num, ascii_count in ascii_pages[:10]:
    print(f"页面 {page_num}: {ascii_count} 个 ASCII 字符")

# 获取页面详细信息
page_info = db.get_page_info(8)
print(f"页面 {page_info['page_num']} 信息")
print(f"  页面类型: {page_info['page_type']}")
if 'type_id' in page_info:
    print(f"  类型ID: {page_info['type_id']}")
    print(f"  桶ID: {page_info['bucket_id']}")
```

### 高级用法

```python
from e3d_db_reader_fix import E3DDatabase

# 打开数据库
db = E3DDatabase('/path/to/database')

# 扫描特定类型的页面
scan_results = db.scan_pages(page_types=[5, 7])  # 只扫描数据页面和特殊页面

# 查找包含特定文本的页面
ascii_pages = db.find_ascii_pages(min_chars=100)  # 至少 100 个 ASCII 字符
for page_num, ascii_count in ascii_pages:
    page_data = db.read_page(page_num)
    # 检查是否包含特定文本
    if b"PIPE" in page_data:
        print(f"页面 {page_num} 包含 PIPE 数据")

# 分析数据页面
data_pages = db.scan_pages(page_types=[5])[5]
for page_num in data_pages[:10]:
    page_info = db.get_page_info(page_num)
    print(f"页面 {page_num}: 桶ID {page_info['bucket_id']}")
```

## 故障排除

### 问题 1: 无法读取数据库文件

**错误信息**:
```
错误: 无法打开数据库文件: [Errno 2] No such file or directory: '/path/to/file'
```

**解决方案**: 检查文件路径是否正确，确保文件存在。

### 问题 2: 扫描页面时出现错误

**错误信息**:
```
警告: 读取页面 X 时出错: unpack requires a buffer of 4 bytes
```

**解决方案**: 这通常发生在文件末尾，工具会自动跳过这些页面。

### 问题 3: 页面类型识别为未知

**输出**:
```
  页面类型:      123456 (未知类型(123456))
```

**解决方案**: 这可能是新的页面类型或自定义页面类型，需要进一步分析。

## 性能建议

1. **扫描大文件**: 对于大型数据库文件（>100MB），扫描可能需要较长时间
2. **批量处理**: 使用 Python API 进行批量处理，而不是多次调用命令行工具
3. **内存管理**: 处理大量页面时，注意内存使用情况
