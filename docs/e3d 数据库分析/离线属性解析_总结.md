# E3D / PDMS 元素属性离线解析 — 总结

> 2026-06-06 · 基于 AVEVA Everything3D 2.10 `core.dll` 实时逆向(IDA)+ 真实样本(sam7200 / acp7002)交叉验证。
> 详细依据见《E3D_DB_文件格式规范.md》§7.6–§7.9、§11 与本计划 `findings.md` §7–§8。

## 1. 成果一句话

**纯文件离线**(无运行时、无 IDA 依赖)解析 E3D/PDMS DABACON 数据库:给定元素记录即可解出
`noun · NAME · refno · owner · 全部隐式属性 · 全部显式(DA)属性 · 引用(连通+目录)`,
并重建 **owner 层级树**、做**跨库引用解析**、导出**整库结构化 JSON**。

## 2. 数据模型全景（4 类文件)

| # | 角色 | 文件 | 关键内容 | 规范 |
| :- | :- | :- | :- | :- |
| 1 | 元素库(设计/目录) | `<proj><dbno>_0001`(sam7200 设计 / acp7002 目录) | 元素记录:隐式区 + DA/显式区 + 成员定位 | §2 / §7.3 / §7.9 |
| 2 | 模式库 / 模板库 | `%AVEVA_DESIGN_EXE%/*vir.dat`(desvir=设计, catvir=目录…) | 每 noun 的 type-def(**offset 来源**)K + 默认值 I/J | §7.7 / §7.7.8 |
| 3 | 属性库 | `attlib.dat` | 属性名/类型/单位/类别、noun→属性列表 | §7.4 |
| 4 | 名称哈希 | (算法) | `db1_hash` base-27 + 0x81BF1(可逆) | §7.5 |

## 3. 端到端解析链

```
元素记录 record[3] = noun hash (base-27)
   │
   ├─ 模式库(desvir.dat 等)二分查 noun → type-def(skeleton K)
   │     └─ 描述符 [hash, stride, type, size, off|bit(主 desc5/备 desc8)]
   │            └─ 隐式值 = record[off..]   (sel=record[w10]>>29&1 选主/备)
   │
   ├─ record[6]=page, record[7]→DA偏移, record[10]>>14=DA字数
   │     └─ DA 链式节点(5字头)→ payload [hash][ctrl:type<<26|n][value]
   │            └─ 显式值(含 NAME=0x9C18E type15;DESC/FUNC type10 文本)
   │
   ├─ record[4..5] = owner refno  → owner→child 连边 = 层级树
   └─ 引用属性(type 4/8/16)= (dbno, refseq) → 全局 refmap 解析(本库 + 跨库目录)
```

## 4. 关键格式速查

- **页**:2048 字节、**大端**。元素库 `page P @ P*2048`(page0=PdmsHeader);模式库 `page P @ (P-1)*2048`(page1=头)。链式页:511 数据字 + 第 512 字=下一页。
- **模式库头(page1)**:`w0==6`、`w5`=类型数、`w7`=类型索引(tlu)页。tlu 每项 7 字 `[noun, Kpg, Kcnt, Ipg, Icnt, Jpg, Jcnt]`(按 noun 升序)。
- **type-def(skeleton K)**:`w9`=描述符数、`w14`=描述符数组起;描述符 `[0]=hash [1]=stride [2]=type [3]=size [5]=主offset|bit [8]=备offset|bit`。
- **取值**:`sel=(record[w10]>>29)&1` 选 `desc[5]`(主)/`desc[8]`(备);`off=desc&0xFFFFF`,`off==0`=不内联。
  - BOOL(5):`(record[off]>>bit)&1`。
  - 标量(size==1 非文本):值直存 `record[off]`。`size>1`/文本:`count@off`,数据 `@off+1`。
  - 实数(2/6):sel=1 → 2 字 double(**低字在前**);sel=0 → 1 字 float(实务未见 sel=0)。
- **显式/DA 区**:`record[6]`=page、`record[7]`→`(>>13)&0xFFF`偏移、`record[10]>>14&0x3FFF`=字数;节点 5 字头(`(u16)=payload+5 | type<<16`,word3/4=下一节点链),payload 同 §7.7.8 条目;文本 `[len][packed 4 字符/字, 高字节在前]`;**NAME=0x9C18E type15**。
- **type-def 类型枚举**(≠attlib §7.1;全库实测 + `db4_get_ce_att` 反编译):**2**=实数标量/**6**=实数向量、**3**=整数标量/**7**=整数数组、**4**=引用标量/**8**=引用数组/**16**=word-引用(2字 `(dbno,refseq)`)、**5**=布尔(位)、**10**=文本(DESC/FUNC)/**15**=NAME 文本(off=0)、**14**=UDA表(UDATAB/UDAFTB)+SPAMAP、**18**=UDA字符串表(UDASTB)、**9/17**=特殊。`size==1 且非文本`=标量(无计数字,值直存 record[off]);余为计数前缀。`sel`(record[10]bit29):sel=1=备 offset/双精度(低字在前)、sel=0=主 offset/单精度 float(本批样本全 sel=1)。
- **引用** = `(dbno, refseq)`(同记录头 refno/owner);`dbno` 本设计库(可解)vs catalogue 库(外部)。
- **skeleton I/J** = 默认值(I=按 offset 的默认记录镜像;J=按 hash 的默认表)。

## 6. 验证结果(纯离线)

- **属性值**:WELD `/WB1` POS=`(9630,8072,5282.5)`、ORI=`(0,90,0)`,与结构化实测逐字吻合;`ele_data_0` POS=`(9630,8224,5130.5)`(独立实测吻合)。
- **整库**:sam7200 → 6536 元素 / 1144 命名 / 140 noun 类型;泛化 NBOX/CTOR/NCYL/CYLI/EQUI/NOZZ… 几何量均合理。
- **层级**:根为 ZONE(`/EQUIPRACK-ACCESS` 子树 1414 …);`EQUI /P1501A → 几何 + NOZZ /P1501A-N1//N2`。
- **连通**:`CREF/HREF/TREF` → 管道分支/设备管嘴/三通(`HREF→/P1502A-N2`)。
- **跨库目录**:sam7200 → acp7002(dbno 15194):`.PSPE→SPEC /AVEVAHVACSPEC`、`.SPRE→SPCO …/STDAHU//RVCD//RSBEND`。
- **规模**:跨设计/目录/系统 + 103MB 大库(ams1112 真实 ~42.2 万元素)均解;Rust 全库 ~2s vs Python ~30s。
- **双实现对齐**:Rust↔Python 属性级 diff —— 目录库 **100%**(34450/34450)、设计库 **99.95%**(implicit 0 mismatch)。
- **CJK**:元素名按 **UTF-8** 解(`/穹顶`、`/天花板`);早期 Python `latin1` 乱码已修。
- **`sel=0`(packed/float)定论**:全库(设计/目录/系统)**0 个干净 sel=0 记录** ⇒ 干净元素 100% sel=1;packed 路径已代码+合成确证,确认不适用干净数据。

## 8. 写入(离线)

- **页无校验和**(`db1_read_page`=仅 FHDBRN、`db1_write_page` 写原始页;§12.1)⇒ 保持大端 +(实型)低字在前,**就地覆盖定长内联值**即字节合法、可读回。
- **安全在位写**(已实现+验证,real/int/ref;不改框架/键 ⇒ 不碰 B 树):Python `e3d_write.py`(`set_inline_value`)+ Rust `pdms_io::e3d_decode::set_inline_value`(5 个 edition-2024 测试覆盖读+全类型写)。实测 WELD `/WB1`:POS→(1000.25,−2000.5,3000.75)、WLDN→777、SPRE→(99,12345)、TSPE→(7,88),改动均限于值区间。
- **完整写机制(已权威分析,未实现)**:COW(`db1_update_page`)+ B 树插入/分裂(`db3_insert_page_entry`/`db3_split_node`,§12.5)+ 会话提交/page0 重指(`db5_save_work` 0x105E9C80,§12.4)。E3D 编辑=多版本追加(旧页留存→COW 新页→追加 sesno+1 会话指新 B 树根→原子重指 page0)。完整离线写实现为独立高风险里程碑(需真 E3D 双读验证基线)。
