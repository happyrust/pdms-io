# E3D Element 属性二进制读取 & 反序列化全链路

> 基于 IDA 逆向 **E3D 3.1 core.dll**（`D:\AVEVA\Everything3D3.1\core.dll`）
> 分析日期：2026-04-13

## 概述

Element 属性读取从应用层到 Dabacon 二进制页面访问共 **5 层**，采用两级缓存 + 类型字典驱动的反序列化策略。

```
L1  PseudoAttPlugger API (getIntAtt / getRealAtt / ...)
L2  BST 缓存 + Handler 虚函数分发
L3  internalGetAtt 决策树
L4  dabGetAtt 游标定位 + 属性值读取
L5  sub_5AB5BC0 页面级二进制记录读取
```

---

## L2：BST 缓存 + 类型分发

以 `getIntAtt` 为例，实际逻辑在 `sub_584DCF0`（`0x584DCF0`）。

### 2.1 属性值 BST 缓存（sub_585AD10 @ 0x585AD10）

```
BST 节点布局:
  +0   : left child ptr
  +4   : right child ptr (经 iterator)
  +8   : (iterator sentinel flag at byte +13)
  +16  : DB_Ref (element reference, 用于 operator< 比较)
  +36  : attribute id (上界)
  +40  : cached int value
```

遍历使用 `DB_Element::operator<` 比较 element reference，若命中且 attributeId < node[36]，直接返回 `node[40]`，**零 DB 访问**。

### 2.2 Handler 虚函数分发（sub_5859FC0 @ 0x5859FC0）

当缓存未命中时：

```
1. actualType = DB_Noun::actualType(element)
2. handler = BST_lookup(actualType, attributeId)  // sub_5932640
3. handler->vtable[6]->vtable[12](element, qualifier, &value)
```

Handler BST 节点以 `(nounId, attributeId)` 为 key。

**三级类型回退**：
```
actualType → (miss)
  └─ UDET contentType = DB_Blob::getContentType(actualType) → (miss)
       └─ hardType = DB_Noun::hardType(actualType) → (miss)
            └─ NOUN_UNKNOWN (通配)
```

### 2.3 Fortran Plugger 回退（runFortranPlugger @ 0x585ca00）

当 Handler 分发返回 error (2, 201) 时：

```
if (DB_Attribute::type() == 1)   // 类型 1
    sub_51E04AA(asPointer, &hashValue, &attId, &qualifier, ...)
else
    sub_51E0F8C(asPointer, &hashValue, &attId, &qualifier, ...)
```

这些是 Fortran shim，内部调用 `GATINT` / `GATPOS` / `GATSTR` 等经典 Dabacon 入口。

## L3：Element 内部获取 — internalGetAtt

**核心函数**：`DB_Element::internalGetAtt` @ `0x593e9c0`

```
internalGetAtt(attribute, qualifier, &value)
│
├─ isDistributedAttribute(attribute, qualifier)?
│    └─ 读 ATT_XRQELE → 获取远程引用元素 → 递归 getAtt
│
├─ type() 校验: 必须为 1 或 6
├─ size() 校验: 必须为 1（标量）
├─ isProtected()? → return false
│
├─ defi() == 4 (默认值定义)?
│    └─ value = 0, 走 PseudoAttPlugger 回路
│
├─ isUDA() (User-Defined Attribute)?
│    ├─ getUda(attribute, qualifier, &rawVector) → 成功
│    │   └─ value = *(_DWORD*)rawVector[0]   // 直接取首个 4 字节
│    └─ 失败 → return false
│
├─ 元素类型解析:
│    ├─ this->noun 为 null 或 NOUN_UNKNOWN → setType()
│    ├─ UDET buildNumber 不匹配 → setType()
│    └─ isPseudo(contentType)? → 跳到 PseudoAttPlugger
│
├─ NOUN_UDA + (ATT_UTYP 或 ATT_ABLE)?
│    └─ 读 ATT_UDACPY(qualifier=0) → 获取副本元素 → 递归 getAtt
│
├─ dtyp() != 1? → error (2, 10) "Invalid data type for int"
│
├─ ★ dabGetAtt(DBE_Base::id(attribute), &value)  ← 主路径
│    └─ 成功 → return true
│
├─ defi() == 1 (必须存在)? → return false
│
└─ 兜底: PseudoAttPlugger::instance()->getIntAtt(...)
```

### ityp 后处理

`getAtt` 外层在 `internalGetAtt` 成功后检查：
```cpp
if (DB_Attribute::ityp(att) == 51 || ityp == 52)
    DB_Uda::oldToNew(&value);  // UDA 格式迁移
```

## L4：Dabacon 二进制访问 — dabGetAtt

### 4.1 标量整数读取（@ 0x592c670）

```
dabGetAtt(int attId, int &value):
  1. elGotoCPP(true)     → 定位元素游标
  2. sub_5AAB800(attId, &value)  → Fortran 级属性读取
  3. 失败 → db_clear_error(), error (2, 201)
```

### 4.2 游标定位 — elGotoCPP（@ 0x59316d0）

```
elGotoCPP(reportError):
  ├─ sub_5AABFE0(535968, cache[6])  → 检查游标缓存
  │    └─ cache[0]==element.ref[0] && cache[1]==element.ref[1] → 已定位
  └─ sub_5AAC300(elementRef) → 实际磁盘/页面 seek
       └─ 失败 → error (2, 202) "Element not found"
```

### 4.3 通用属性值读取 — dabGetAtt(DB_AttributeValue)（@ 0x592d1e0）

根据 `DB_Attribute::dtyp()` 做类型路由：

| dtyp | 数据类型 | 标量读 | 数组读 |
|------|---------|--------|--------|
| 1, 6, 10 | Integer | `dabGetAtt(id, int&)` | `dabGetAtt(id, vector<int>&)` |
| 2, 7, 8, 9 | Real/Double | `dabGetAtt(id, double&)` | `dabGetAtt(id, vector<double>&)` |
| 3 | Boolean | `dabGetAtt(id, bool&)` | `dabGetAtt(id, vector<bool>&)` |
| 4 | Table/Qualifier | `dabGetTableAtt` | `dabGetTableAtt(+vector)` |
| 5 | Element Ref | `dabGetAtt(id, DB_Element&)` | `dabGetAtt(id, vector<DB_Element>&)` |
| 11 | String | `dabGetAtt(id, string&)` | `dabGetAtt(id, vector<string>&)` |
| 12 | Blob | `dabGetAtt(id, DB_Blob&)` | — |

数组判断：`DB_Element::isDabArrayType(attribute, -1)` 决定走标量还是数组路径。

### 4.4 Fortran 入口 GATINT（@ 0x5a35c90）

```
GATINT(noun, hashRef, attPtr, startIndex, endIndex, qualifier, output, count, error):
  1. DB_Ref::DB_Ref(noun, *hashRef) → 构造元素引用
  2. DB_Element::DB_Element(ref)    → 构造 Element
  3. DB_Attribute::findAttribute(*attPtr, &attObj)  → 字典查找
  4. DB_Qualifier::AssignQualifier(qualifier)
  5. 分支:
     ├─ size==1: getAtt(attObj, qualifier, &intValue) → output[0] = intValue
     └─ size>1:  getAtt(attObj, qualifier, &intVector)
                 → memcpy(output + startIndex, vector + startIndex, count*4)
                 → 上限 5000 (error 136 if exceeds)
```

## L5：记录级二进制读取 — sub_5AB5BC0

**最底层**，直接操作 Dabacon 页面缓冲区。

### 5.1 调用链

```
sub_5AAB800(attId, &value)
  └─ sub_5AC8160(490, attId, &value)    // 命令号 490
       └─ sub_5AB5BC0(attId, requestedType, count, &value, buffer, flags)
```

### 5.2 记录定位

```
sub_5AB5920(0, attId, &recordPtr) → 页面内属性记录
  recordPtr+8  = storedType (实际存储类型)
  recordPtr+12 = arraySize
  recordPtr+20 = data offset (非 large record)
  recordPtr+32 = data offset (large record, bit29 标志)
```

### 5.3 类型兼容矩阵

| 请求类型 | 兼容的存储类型 |
|---------|--------------|
| 3 (Bool) | 3, 7, 14 |
| 4 (Ref) | 4, 16 |
| 6 | 6, 21 |
| 10 | 10, 22 |
| 19 | 19, 23 |
| 其他 | 必须完全匹配 |

不兼容时返回 error 17：`"Actual type is %s"`。

### 5.4 页帧寻址 & 二进制反序列化

```
pageFrame = dword_6A54024 + 4 * (15 * pageIndex + 4)
pageBitmap = *(*(pageFrame+4) + 4*pageFrame[48] + 40)

if (pageBitmap & 0x20000000)  // bit29 = large record
    dataOffset = recordPtr + 32
else
    dataOffset = recordPtr + 20

recordData = dataOffset & 0xFFFFF  // 20-bit offset within page

if (recordData == 0)
    dispatcher = sub_5AB4CF0    // null/empty → 返回默认值
else
    dispatcher = sub_5AB5600    // 正常读取 → 按 storedType 反序列化

dispatcher(pageFrame, attId, recordPtr, type, isArray, count, &value, buffer, flags)
```

## 关键数据结构

### DB_Element 内存布局（部分）

```
+0   : vtable
+4   : DLL_GlobalInterface* (含 error state)
+12  : DB_Noun* noun (元素类型, null/NOUN_UNKNOWN 触发 setType)
+16  : DB_Blob* udetBuildNumber
+20  : DB_Ref[2] (element reference words)
```

### DB_Attribute 关键方法

| 方法 | 含义 |
|------|------|
| `type()` | 属性大类 (1=标准, 6=扩展, 12=blob) |
| `dtyp()` | 数据类型 (1=int, 2=real, 3=bool, ...) |
| `size()` | 标量=1, 数组>1 |
| `defi()` | 定义类型 (1=必须, 4=默认) |
| `ityp()` | 内部类型 (51,52=UDA) |
| `isUDA()` | 用户自定义属性 |
| `isTable()` | 表属性 |
| `findAttribute(id)` | 全局字典查找 |

### 全局状态

| 地址 | 含义 |
|------|------|
| `dword_6A54024` | 当前活跃页帧指针 |
| `dword_6A54028` | 备用页帧指针 |
| `dword_6A5402C` | 页帧保存槽 |
| `dword_6A54030` | 当前页表项指针 |
| `dword_6453B98` | Dabacon 错误码 (0=成功) |
| `dword_6423B60` | 嵌套调用标志 |

## 性能机制

### 两级缓存

1. **属性值 BST 缓存**（L2）：按 (ElementRef, AttributeId) 缓存最近读取的值，命中时完全跳过 DB 层
2. **元素游标缓存**（L4）：`elGotoCPP` 检查上次定位的元素是否与当前相同，避免重复 seek

### 性能监控

`sub_584DCF0` 内置 `QueryPerformanceCounter` 计时：
```
if (elapsed_ms > dword_5FFFD48 && dword_5FFFD4C)
    if (!DB_Attribute::getBool(att, 116939309))
        sub_5857EE0(...)  // 性能告警/缓存淘汰
```

## 应用层调用示例（伪代码）

```cpp
// 读取元素的 BORE 属性 (整数)
DB_Element elem = ...;
DB_Attribute* att = DB_Attribute::findAttribute(ATT_BORE_ID);
int bore_value;

// 方式1: 通过 PseudoAttPlugger
DB_PseudoAttPlugger* plugger = DB_PseudoAttPlugger::instance();
MR_Message msg;
bool ok = plugger->getIntAtt(elem, att, DB_Qualifier::empty(), &bore_value, &msg);

// 方式2: 通过 DB_Element 直接调用
bool ok = elem.getAtt(att, bore_value);
// 内部: internalGetAtt → dabGetAtt → elGotoCPP + sub_5AAB800

// 方式3: 通过 Fortran 层
GATIN1(noun, hashRef, attId, &value, &error);
// 内部: ATAINT 类型校验 → GATINT → DB_Element::getAtt
```
