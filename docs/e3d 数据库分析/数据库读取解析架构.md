# E3D/PDMS 数据库读取解析架构（E3D 3.1）

> 基于 core.dll 逆向分析 + pdms-io-fork Rust 实现对照

## 1. 总览

```mermaid
graph TD
    A[应用层: PML / DB_DB C++] -->|db_open_read_db| B[db5: 数据库访问层]
    B -->|db_go_to_element| C[db4: 元素/属性管理]
    C -->|db_get_integer / db_get_string ...| D[db4: 属性读取]
    D -->|索引查找| E[db3: B-树索引]
    E -->|页码定位| F[db1: 页面缓存]
    F -->|缓存未命中| G[Fortran I/O: FHDBRN]
    G --> H[DirectAccessToken::read]
    H --> I[OS ReadFile]

    F -->|缓存命中| J[直接返回内存页]
```

## 2. 阶段一：打开数据库

### 2.1 调用链

```
DB_DB::openRead(session_no)                    // C++ 入口
  → DB_DB::openFile(mode=7)                    // 0x590BAC0
    → QU_Buffer::Append(project_path)
    → FIOXST(filename, dbno*100+mode, ...)     // Fortran: 打开已有文件
    → DB_DB::addToTokenLookup()                // 注册 token 到查找表
    → 设置 openMode = "FILEREAD"
```

### 2.2 文件名构造

```mermaid
graph LR
    A[makeDirectoryName] --> B["目录路径/"]
    B --> C[projectName]
    C --> D[appendDBFileName]
    D --> E["补零3位: 001, 005, 042"]
```

`DB_DB::appendDBFileName` (0x58F4F10) 将 db 编号补零到 3 位：

```
dbno=1  → "001"
dbno=5  → "005"
dbno=42 → "042"
```

完整路径: `<project_dir>/<project_name>001` ~ `<project_name>NNN`

### 2.3 文件打开模式

| mode 参数 | 含义 | openMode 字符串 |
| :--- | :--- | :--- |
| 7 | 只读 | `FILEREAD` |
| 1 | 只读 | `FILEREAD` |
| 6 | 共享读 | `FILEREAD` |
| 其他 | 读写 | `FILEWRITE` |

实际 FIOXST 参数: `dbno * 100 + mode`，如 db1 只读 = 107。

## 3. 阶段二：元素定位

### 3.1 导航到目标元素

```
db_go_to_element(element_ref)                  // opcode=108
  → dispatcher sub_5ACF400
    → 将 CE (Current Element) 指针移动到目标元素
    → 内部通过 B-树索引定位页面
```

### 3.2 B-树索引查找 (db3)

```mermaid
graph TD
    A[db3: 查找元素] -->|FHSRCH 0x5469180| B[从根节点开始]
    B --> C{key 在当前节点?}
    C -->|是| D[返回页码+偏移]
    C -->|否| E[FHITER 0x546DD8E 遍历子节点]
    E --> F[FHNPTH 0x546D970 路径解析]
    F --> C
```

B-树节点结构（从 FHSRCH 反编译推断）:
- 每个索引页包含有序的 key-value 对
- key = 元素 hash 或 refno
- value = (dbno, page_no, offset)

### 3.3 DB_IndexTableIterator

```
DB_IndexTableIterator::ctor(db, element)       // 0x5A19150
  → 初始化搜索上下文
  → 定位第一个匹配的索引条目

DB_IndexTableIterator::increment()             // 0x5A1AD00
  → 移动到下一个索引条目
  → 用于遍历所有匹配元素
```

## 4. 阶段三：页面读取 (db1)

### 4.1 db1_get_page 完整流程

```mermaid
flowchart TD
    START[db1_get_page<br/>0x5AEE4E0] --> CHECK[db1_is_page_incore<br/>0x5AF04A0<br/>检查缓存池]
    CHECK -->|命中| HIT[增加 lock_count<br/>设置 referenced bit<br/>更新统计计数器]
    HIT --> RETURN[返回页面数据指针]
    
    CHECK -->|未命中| ALLOC[db1_plu_locate_entry<br/>0x5AEF150<br/>LRU 分配槽位]
    ALLOC -->|失败| ERR[返回 0]
    ALLOC -->|成功| SETUP[设置页面描述符:<br/>dbno, page_id, extent]
    
    SETUP --> LOCALCACHE{本地文件缓存<br/>sub_5BCC210?}
    LOCALCACHE -->|命中| COPYFROMCACHE[从本地缓存复制数据]
    LOCALCACHE -->|未命中| PREFETCH{多页预读?<br/>dword_6A5415C > 1}
    
    PREFETCH -->|是| BATCHREAD[批量读取 N 页<br/>到 dword_6A54158 缓冲]
    PREFETCH -->|否| SINGLEREAD[单页读取]
    
    BATCHREAD --> DISKREAD[db1_read_page<br/>0x5AF0640]
    SINGLEREAD --> DISKREAD
    
    DISKREAD --> FHDBRN[FHDBRN 0x5B8D4F0<br/>→ DirectAccessToken::read]
    FHDBRN -->|成功| CLASSIFY[页面类型分类<br/>type=5: 元素页<br/>type=7: 续页]
    FHDBRN -->|失败 err=11| RETRY[SYWAIT 等待<br/>→ FHSWIT 切换模式<br/>→ 重试]
    RETRY --> FHDBRN
    
    CLASSIFY --> WRITECACHE[写入本地文件缓存<br/>sub_5BCC240]
    COPYFROMCACHE --> RETURN
    WRITECACHE --> RETURN
```

### 4.2 页面缓存命中检查 (db1_is_page_incore)

`sub_5AF04A0` 遍历页面描述符池 `dword_6A540EC`，匹配 (dbno, page_id, extent)。

返回值:
- 0 = 未命中
- N > 0 = 缓存池中的 pfno (physical frame number)

### 4.3 磁盘读取重试机制

```mermaid
sequenceDiagram
    participant GP as db1_get_page
    participant RP as db1_read_page
    participant FH as FHDBRN
    participant DAT as DirectAccessToken
    participant OS as OS I/O

    GP->>RP: read_page(token, page_no, buffer, page_size)
    RP->>FH: FHDBRN(token, page_no, buffer, file_handle)
    FH->>DAT: vtable[16](page_no, buffer, size, 1)
    DAT->>OS: ReadFile(offset=page_no*page_size, size)
    
    alt 成功
        OS-->>DAT: OK
        DAT-->>FH: OK
        FH-->>RP: 1
    else 失败 (err=11 文件锁)
        OS-->>DAT: FAIL
        DAT-->>FH: 0
        FH-->>RP: 0
        RP->>RP: SYWAIT(0.5s) 等待
        RP->>FH: FHDBRN (重试)
        alt 仍失败
            FH-->>RP: 0
            RP->>RP: FHSWIT → "CLOSED"<br/>FHSWIT → 原模式
            RP->>FH: FHDBRN (第三次)
        end
    end
```

## 5. 阶段四：属性解析 (db4)

### 5.1 属性读取分派

```mermaid
graph TD
    A[db_get_integer<br/>opcode=80] --> D[sub_5AC8160]
    B[db_get_string<br/>opcode=106] --> E[sub_5ACDA10]
    C[db_get_real] --> F[dispatcher]
    G[db_get_reference] --> H[dispatcher]
    I[db_get_logical] --> J[dispatcher]
    K[db_get_int_array] --> L[dispatcher]
    M[db_get_ref_array] --> N[dispatcher]
    
    D --> O[从 CE 当前页面<br/>读取整型属性值]
    E --> P[从 CE 当前页面<br/>读取变长字符串]
```

### 5.2 元素页面数据布局

从 `db1_get_page` 返回的页面数据（type=5 元素页）内部结构：

```
┌──────────────────────────────────────────────────┐
│ 页头 (page header)                                │
│   word[0]: page_type (5=元素页, 7=续页)           │
│   word[1]: magic/tag                              │
│   word[2]: 元素计数                                │
│   word[3]: 下一页链接 (negative = 最后)            │
├──────────────────────────────────────────────────┤
│ 元素记录 0                                        │
│   ├─ 元素类型 hash (db1_hash 计算)                │
│   ├─ 固定属性区 (FOWN, LOWN, PREX, NEXX...)      │
│   ├─ 可变属性区 (NAME, DESC, 用户属性)            │
│   └─ 续页指针 (若数据超过一页)                     │
├──────────────────────────────────────────────────┤
│ 元素记录 1 ...                                    │
├──────────────────────────────────────────────────┤
│ 空闲空间 / 填充                                   │
└──────────────────────────────────────────────────┘
```

### 5.3 跨页读取 (续页 type=7)

当元素数据超过单页时，通过 0x07 段合并机制拼接:

```mermaid
graph LR
    A["页面 N (type=5)<br/>元素开始<br/>续页指针→M"] --> B["页面 M (type=7)<br/>续数据<br/>续页指针→P"]
    B --> C["页面 P (type=7)<br/>续数据<br/>指针<0=结束"]
    
    D[ElementRecordReader] --> A
    D --> B
    D --> C
    D --> E[拼接完整元素数据]
```

## 6. 完整读取调用链（端到端）

```mermaid
sequenceDiagram
    participant App as 应用层
    participant DB5 as db5 (访问层)
    participant DB4 as db4 (元素层)
    participant DB3 as db3 (索引层)
    participant DB1 as db1 (页面层)
    participant FIO as Fortran I/O
    participant OS as 操作系统

    App->>DB5: db_open_read_db(dbno, session)
    DB5->>FIO: FIOXST(filename, mode)
    FIO->>OS: OpenFile
    OS-->>FIO: file_handle
    
    App->>DB4: db_go_to_element(refno)
    DB4->>DB3: B-树搜索(refno)
    DB3->>DB1: db1_get_page(index_page)
    DB1->>DB1: 缓存查找
    DB1->>FIO: FHDBRN (如未命中)
    FIO->>OS: ReadFile
    DB3-->>DB4: (dbno, page_no, offset)
    
    DB4->>DB1: db1_get_page(element_page)
    DB1-->>DB4: 页面数据指针
    
    App->>DB4: db_get_integer(ATT_ID)
    DB4->>DB4: 从页面数据 + offset 读取属性
    DB4-->>App: 属性值
    
    App->>DB4: db_get_string(ATT_NAME)
    DB4->>DB4: 从页面数据读取字符串
    Note over DB4: 若字符串跨页:
    DB4->>DB1: db1_get_page(续页)
    DB1-->>DB4: 续页数据
    DB4-->>App: 完整字符串
```

## 7. 与 pdms-io-fork 的对应

| 解析阶段 | core.dll 函数 | pdms-io-fork (Rust) |
| :--- | :--- | :--- |
| 打开文件 | `FIOXST` → OS Open | `File::open(path)` |
| 页面读取 | `db1_get_page` → `FHDBRN` | `PageManager::get_page` → `read_page_from_file` |
| 页面缓存 | 描述符池 `dword_6A540EC` | `PageManager.cache` HashMap |
| 跨页拼接 | type=7 续页链接 | `ElementRecordReader::read` (0x07 continuation) |
| 属性解析 | `db_get_integer/string/...` | `io.rs` 中的 `read_*` 系列方法 |
| B-树索引 | `FHSRCH/FHXPND/FHITER` | `io.rs` 中的 `find_refno` / `find_key` |
| 页面大小探测 | `dword_6453DC4 × 4` | `defines::PAGE_SIZE_512` / `PAGE_SIZE_2K` |
