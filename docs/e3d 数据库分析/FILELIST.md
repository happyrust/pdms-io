## 使用流程

### 1. 阅读文档
1. 先阅读 `README.md` 了解项目概述
2. 阅读 `E3D_数据库文件架构完整分析.md` 理解文件架构
3. 阅读 `E3D数据库文件读取分析.md` 了解具体分析方法
4. 阅读 `快速开始.md` 学习如何使用工具

### 2. 使用工具
1. 使用 `e3d_db_reader_fix.py` 分析数据库文件
2. 参考 `快速开始.md` 中的示例命令
3. 使用 `info` 命令查看数据库信息
4. 使用 `scan` 命令扫描所有页面
5. 使用 `page` 命令查看指定页面

### 3. 深入分析
1. 参考技术文档理解页面结构
2. 使用工具提取需要的数据
3. 根据文档中的信息进行二次开发
