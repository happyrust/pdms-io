# PDMS 表达式解析 - Opcode 对照表

## 1. 二进制数据格式

```
┌─────────────────────────────────────────────────────────────┐
│  属性头 (8字节)                                              │
│  ├── 4字节: 属性 hash                                        │
│  └── 4字节: 属性类型 flag (0x65=表达式, 0x66=字符串)          │
├─────────────────────────────────────────────────────────────┤
│  表达式数据                                                  │
│  ├── 4字节: 表达式长度 (word数量)                            │
│  └── N×4字节: 表达式 opcode 序列                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 值类型 opcode (操作数入栈)

| opcode | 名称 | 格式 | 示例 |
|--------|------|------|------|
| `0x65` | 数值 | `0x65, count, v1, v2, ...` | `0x65, 6, -1, 0, 0, 0` → `-1` |
| `0x66` | 字符串 | `0x66, len, chars...` | → `'HELLO'` |
| `0x67` | 布尔值 | `0x67, value` | `0x67, 201` → `true` |
| `0x6A` | 属性引用 | `0x6A, hash, low, high, suffix` | → `PARAM 4` |
| `0x6F` | PI常量 | `0x6F` | → `PI` |
| `0x72` | 变量 | `0x72, hash` | → `VAR1201` |
| `0x74` | 特殊函数1 | `0x74, value` | → `PREV` |
| `0x75` | 特殊函数2 | `0x75, value` | → `CATR` |

## 4. 解析算法

后缀表达式栈求值：
```
输入: [0x65, 6, -1, 0x6A, hash, 4, 0x6A, hash, 7, 801, 802]
栈操作: 值入栈 → 运算符弹出计算 → 结果入栈
输出: "-1 TIMES SUM PARAM 4 PARAM 7"
```

优先级:
```rust
PREC_OR = 10
PREC_AND = 20
PREC_ADD = 60
PREC_MUL = 70
PREC_FUNC = 90
```
