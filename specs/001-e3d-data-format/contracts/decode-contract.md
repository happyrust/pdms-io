# Contract: 解码 / 编码不变式

> 任何实现(Rust `crates/e3d_io` 或 Python 参考)MUST 满足以下契约;违反即缺陷。这些是双实现对齐与回归测试的判据来源。

## C1. 解码契约(读)

- **C1.1 偏移权威**:隐式属性 offset 仅来自模式库 `*vir.dat` type-def `desc[5|8]`;`sel=(record[w10]>>29)&1` 选主/备。
- **C1.2 标量 vs 计数**:`size==1 且非文本` ⇒ 值直存 `record[off]`;否则 `count@off` + 数据 `@off+1`。
- **C1.3 实数字序**:type 2/6 sel=1 ⇒ 2 字双精度,**低字在前**。
- **C1.4 文本编码**:文本(type 10/14/15)按 `[byte_len][packed 高字节在前]` + **UTF-8** 还原。
- **C1.5 DA 链式**:DA/成员区 MUST 顺 `w3/w4` 链先拼接全部 payload 再解析;NAME = DA hash `0x9C18E`。
- **C1.6 引用**:type 4/8/16 ⇒ `(dbno, refseq)`;跨库经 refmap 解析,未命中以 `=dbno/refseq` 原样。
- **C1.7 健壮性**:短 skeleton-K(<10 字)返回无 schema(不崩溃);脏/误报条目按有效性过滤剔除。
- **C1.8 遍历界定**:B 树条目数以 `word6` 界定;遍历上界 ≥ 4,000,000。

## C2. 编码契约(写,COW)

- **C2.1 不可变**:绝不改旧页;所有改动 append;**唯一**就地变更 = page0 会话指针 `0x28`。
- **C2.2 多版本**:提交后新会话读回新值、所有前序会话逐字节不变、可读原值。
- **C2.3 自包含修正**:COW 数据页后 MUST 修正记录页内 `rec[6]`(DA)/`rec[8]`(成员)指向新页;重定位时 `rec[6]≠旧页` 时对其 no-op。
- **C2.4 B 树正确性**:插入/分裂后 MUST `nav_ok`(二分可达每键)+ 平衡 + 有序 + 无重复;最大键追加不改分隔键;不做下溢合并。
- **C2.5 默认副本**:写默认输出副本;`--inplace` 显式开关。

## C3. 对齐契约(双实现)

- **C3.1 目录库**:Rust↔Python 逐元素逐属性 **100%** 一致(acp7002 34450/34450)。
- **C3.2 设计库**:隐式属性 **0 mismatch**(sam7200);差异仅允许出现在 NAME 探测边界(权威容差上限 **<0.05%**,实测 <0.01%)。
- **C3.3 计数**:整库 element_count / refmap_size 双实现一致。
