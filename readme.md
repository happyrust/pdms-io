  结果里有pe id + sesno 的情况，所以这里需要用枚举的数据结构来表达
  pub enum HisRefno {
      PE(Refno),
    	PES((Refno, i32)), // (Refno, sesno)
  }
  查询出来的结果有可能是有历史数据的，所以这里需要做个区分
- 参考号被删除的处理，直接加字段 deleted，然后在查询的时候，直接过滤掉 is_deleted 为 true 的数据即可, 因为删除的数据不可能在历史数据中，始终是最后一个，也就是
  说，历史数据中，不会有删除的数据，在 pe 里有这个 deleted 字段，如果是 true，则表示是删除的数据
- 新增的判断，在遍历历史数据时，检查是否有新增的数据，如果是新增，需要添加字段 Operation::Add
- 修改的判断，在遍历历史数据时，检查是否有修改的数据，如果是修改，需要添加字段 Operation::Modify, 修改的判断还需要去比较 json 数据，如果两边的 json 数据不一样，则表示是修改
  否则，表示是为 Duplicate，添加字段 Operation::Duplicate，检查 json 是否一致。最新的数据只需要 update 一下就可以了，不用删除，
